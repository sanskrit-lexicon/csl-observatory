_Created: 18-11-2026 · Last updated: 18-11-2026_

**Dataset ID:** `csl-obs/org-metrics@1.0.0` · **snapshot:** `csl-obs/org@1.0.0`, as of `2026-11-16T10:39:19Z` (from `data/manifest.json`) · **machine description:** [`data/org_metrics_dataset.json`](../data/org_metrics_dataset.json), generated by [`scripts/org_metrics_dataset.py`](../scripts/org_metrics_dataset.py).

This is the agenda move-5 companion to A15 (*CDSL as a GitHub maintenance ecosystem*). The A15 draft reports org metrics; this page makes the underlying corpus citable as a dataset. It does **not** mint a DOI, re-cut the data or call the live API.

## What is citable

The committed build emits **38 distributions** and **37 documented exclusions** over the snapshot named above. Every distribution carries `name`, `contentUrl`, `encodingFormat`, `contentSize`, a SHA-256 digest and the catalogue description; every exclusion names a reason. The OBS-T correction corpus is excluded because it is a separate data release with its own concept DOI ([10.5281/zenodo.21346705](https://doi.org/10.5281/zenodo.21346705)); LFS pointers without a local blob are excluded rather than given a fake digest.

Rebuild and verify in one command pair:

```bash
python scripts/org_metrics_dataset.py            # regenerate data/org_metrics_dataset.json
python scripts/org_metrics_dataset.py --check    # refuse on drift
python scripts/update_headline_numbers.py --check # the existing headline gate, unchanged
```

## Divergence is a finding, not an error to hide

Two snapshots coexist: `csl-obs/org-live@1.0.0` (live API, front page) and `csl-obs/org@1.0.0` (offline, findings). They do not agree. This dataset describes the **offline** one; [`reports/snapshot_divergence.md`](../reports/snapshot_divergence.md) records why. A citation must carry the dataset ID and as-of date — a bare "the observatory says" number is not reproducible.

## Honest limitations

- No person-level data is redistributed here; contributor tables carry login aliases, and 9 logins remain unidentifiable.
- `merged_at` is absent from the snapshot, so merged and closed-unmerged PRs are indistinguishable — A15's agent-lane claims must not treat them as equivalent.
- The dataset is a view of public GitHub metadata, so an analysis based on it inherits GitHub's own visibility and deletion biases.
