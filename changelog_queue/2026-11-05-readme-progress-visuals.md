# README progress visuals — per-dictionary correction bars for dictionary repos (H7720)

**[`tools/render_readme_visuals.py`](https://github.com/sanskrit-lexicon/csl-observatory/blob/main/tools/render_readme_visuals.py) renders a compact per-dictionary progress card as a committed static SVG from the OBS-T snapshot alone — `data/manifest.json` for the org snapshot date, `observatory/site/src/data/obs_t_dict.csv` for per-dictionary events/entries, `obs_t_summary.json` for the event date range — with no network, no fonts (ASCII labels), and no timestamps, so the same committed inputs regenerate a byte-identical SVG (`--dict mw` for one card, `--all` for every key, `--out` to vendor the card into a dictionary repo). The bar scale is the snapshot's most-corrected dictionary, and every number on the card cites the snapshot in its caption (readme-truth-pass). Committed output: `assets/readme/mw-progress.svg` (1,473 bytes), the canonical copy vendored byte-identical into [MWS](https://github.com/sanskrit-lexicon/MWS) `docs/assets/progress-mw.svg` as the enthusiast-README pilot of H7720; refresh rides the monthly correction-batch PR. Registered in the CLI --help smoke list; ruff clean at the 690 baseline.**
