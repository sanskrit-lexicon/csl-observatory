## Attribution rule

Ordered, first match wins — full statement in `scripts/agent_lane.py`:

1. **bot** — author login ends `[bot]` (dependabot, renovate, …).
2. **agent** — human author + explicit marker: handoff ID `h\d{3,5}` in the
   head branch (worktree convention, e.g. `h5602-drain`, `h543-yo-sweep`),
   an agent-tool / batch-deploy branch prefix (`codex/`, `claude/`,
   `cologne-batch-deploy/`, …), a handoff ID in the title, an AI model
   named in the title, or an agent marker in the PR body (handoff refs,
   co-author trailers, "generated with", model names — committed as the
   `agent_marker_body` boolean). Default is `human`, so unmarked agent work
   undercounts the agent lane — the error is one-sided by construction.
3. **human** — everything else.

**Measured misclassification (30-PR hand-checked stratified sample,
`reports/agent_lane_adjudication.csv`): 0/30 = 0.0% (calibrated rule) — the pre-calibration `h\d{4}` rule missed 9/30 = 30.0%, all agent→human undercounts**
